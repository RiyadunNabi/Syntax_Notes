## 2. Binder kernel support check

Waydroid needs Android's `binder` IPC in the kernel. Older guides check for `CONFIG_ANDROID_BINDER_IPC` / `CONFIG_ANDROID_BINDERFS`, but on newer kernels (Pop!_OS's `7.0.11-76070011-generic` included) these have been superseded by the **Rust binder driver**.

```bash
zgrep BINDER /boot/config-$(uname -r)
```
```
# CONFIG_ANDROID_BINDER_IPC is not set
CONFIG_ANDROID_BINDER_IPC_RUST=y
CONFIG_ANDROID_BINDER_DEVICES="binder,hwbinder,vndbinder"
```

Checked for `CONFIG_ANDROID_BINDERFS` explicitly — not present as a separate flag on this kernel (expected; superseded by rust_binder handling device creation itself):

```bash
zgrep BINDERFS /boot/config-$(uname -r)
# (no output)
```

**Verdict:** `CONFIG_ANDROID_BINDER_IPC_RUST=y` present → binder support is available via `rust_binder.ko`. This is the modern equivalent of the old C driver + binderfs combo (merged upstream around kernel v6.18). Waydroid 1.6.2+ supports this natively. **No extra module install was needed.**

> **Known minor caveat on rust_binder kernels:** some system audio routed through OMX (e.g. the stock Android music app) may glitch, while apps handling their own audio pipeline (e.g. VLC) are unaffected. Not encountered as a blocker in this setup.

## 4. Start the container and session

```bash
sudo systemctl start waydroid-container
waydroid session start
```

Wait for `Android with user 0 is ready` in the output.

Launch the full UI:
```bash
waydroid show-full-ui
```

✅ **Confirmed working** — Android home screen opened as a window on the GNOME desktop.

---

## 5. Install an APK

With a session running:
```bash
waydroid app install /path/to/your.apk
```

Example:
```bash
waydroid app install ~/Downloads/yourapp.apk
```

The installed app appears in the Waydroid launcher (`waydroid show-full-ui`) alongside the default apps.

**Caveat (VANILLA image, no GApps):** Apps depending on Google Play Services (push notifications, Maps SDK, in-app purchases, etc.) may crash or misbehave — expected, not a bug. Plain APKs (F-Droid-style apps, games, utilities) install and run fine.

## 7. Optional tweaks (not yet applied)

**Multi-window mode** — apps open in separate resizable windows instead of one fullscreen Android UI:
```bash
waydroid prop set persist.waydroid.multi_windows true
waydroid session stop && waydroid session start
```

**Google Play / GApps** — would require reinitializing with a GAPPS-flavored image (`-c` pointed at a gapps system URL) instead of the VANILLA one used here. Bigger download, and Google's SafetyNet/Play Integrity will likely still flag the device as unregistered. Not done in this setup — sideloading plain APKs only.

## 8. Troubleshooting reference (if things break later)

- **`Failed to load binder driver` / binder module not found:** Usually means the running kernel lacks binder support entirely (older/custom kernels). Check with:
  ```bash
  zgrep -i binder /boot/config-$(uname -r)
  ```
  On Pop!_OS's stock System76 kernel this hasn't been an issue since `CONFIG_ANDROID_BINDER_IPC_RUST` ships built-in.

- **Session won't start / container errors:** Check the container service status:
  ```bash
  sudo systemctl status waydroid-container
  journalctl -u waydroid-container -e
  ```

- **Audio glitches in system apps (OMX-based):** Known cosmetic issue on rust_binder kernels as of mid-2026 (tracked upstream in the Waydroid GitHub issues). Apps with their own audio pipeline (VLC etc.) are unaffected.

- **General debugging:** Waydroid develops fast — always check:
  ```bash
  waydroid --version
  ```
  and compare against the [official issue tracker](https://github.com/waydroid/waydroid/issues) if something that used to work suddenly breaks after a system update.
