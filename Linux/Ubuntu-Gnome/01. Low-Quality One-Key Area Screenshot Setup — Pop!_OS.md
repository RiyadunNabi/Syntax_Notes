# Low-Quality One-Key Area Screenshot Setup — Pop!_OS

This guide sets up a keyboard shortcut (**Insert** key) that:
- Lets you select an area of the screen to screenshot
- Compresses it to low quality (small file size)
- Saves it to `~/Pictures/Low_Screenshots`
- Copies it to your clipboard automatically (so you can paste it anywhere)

Your **Print Screen** key stays untouched — still does the normal full-quality screenshot.

---

## Step 1: Install the required tools

Open a terminal (`Ctrl+Alt+T`) and run:

```bash
sudo apt install gnome-screenshot imagemagick xclip
```

Enter your password if asked, and press `Y` if it asks to confirm installation.

- `gnome-screenshot` → takes the screenshot
- `imagemagick` → compresses the image
- `xclip` → copies the image to clipboard

---

## Step 2: Create a folder for your scripts

```bash
mkdir -p ~/scripts
```

This just creates a `scripts` folder in your home directory (if it doesn't already exist).

---

## Step 3: Create the script file

Run:

```bash
nano ~/scripts/lowres-screenshot-area.sh
```

This opens a blank file in the **nano** text editor inside your terminal.

Now **copy the entire block below** and **paste it** into the nano window.
(To paste in most terminals: `Ctrl+Shift+V`)

```bash
#!/bin/bash
mkdir -p ~/Pictures/Low_Screenshots
TMP=/tmp/temp_ss_area.png
FILE=~/Pictures/Low_Screenshots/screenshot_$(date +%Y%m%d_%H%M%S).jpg

gnome-screenshot -a -f "$TMP"
# if user cancels selection, temp file won't exist — exit quietly
[ -f "$TMP" ] || exit 0

convert "$TMP" -quality 30 "$FILE"
xclip -selection clipboard -t image/jpeg -i "$FILE"
rm "$TMP"

notify-send "Screenshot saved" "$FILE"
```

### How to save and exit nano:
1. Press `Ctrl+O` (that's the letter O, not zero) → this **writes/saves** the file
2. It'll show the filename at the bottom — just press `Enter` to confirm
3. Press `Ctrl+X` → this **exits** nano

You're back at the normal terminal prompt now.

---

## Step 4: Make the script executable

Run:

```bash
chmod +x ~/scripts/lowres-screenshot-area.sh
```

This just tells Linux "this file is allowed to run as a program."

---

## Step 5: Find your username (if needed)

Run:

```bash
whoami
```

This prints your username — you'll need it for the next step if your home folder isn't `/home/riyad`.

---

## Step 6: Set up the keyboard shortcut

1. Open **Settings**
2. Go to **Keyboard**
3. Scroll down and click **Keyboard Shortcuts** (or **View and Customize Shortcuts**)
4. Scroll to the bottom and click **Custom Shortcuts** → **+ (Add Shortcut)**
5. Fill in:
   - **Name:** `Low Quality Area Screenshot`
   - **Command:** `/home/riyad/scripts/lowres-screenshot-area.sh`
     *(replace `riyad` with your actual username from Step 5, if different)*
6. Click **Add** / **Set Shortcut**
7. When it asks you to press a key combo, just press the **Insert** key by itself
8. Save

---

## Step 7: Test it

1. Press **Insert**
2. Your cursor should turn into a crosshair — click and drag to select an area
3. Release to capture
4. You should get a notification saying "Screenshot saved"
5. Check the file exists:

```bash
ls ~/Pictures/Low_Screenshots
```

6. Try pasting (`Ctrl+V`) into any app (like GIMP, a chat app, etc.) to confirm the clipboard copy worked

---

## Troubleshooting

**Insert key doesn't do anything:**
Some laptops don't have a dedicated Insert key, or it's a secondary function (needs `Fn+Insert`). Try that combo instead when setting the shortcut in Step 6.

**No notification popup appears:**
Not a big deal — the screenshot still saves. You can check the folder manually.

**Want a different quality level:**
Open the script again with:
```bash
nano ~/scripts/lowres-screenshot-area.sh
```
Change `-quality 30` to any number 1–100 (lower = smaller file, worse quality). Save with `Ctrl+O`, `Enter`, then exit with `Ctrl+X`.

**Want a different save folder:**
Same steps as above — just change `~/Pictures/Low_Screenshots` to whatever path you want in both the `mkdir` line and the `FILE` line.
